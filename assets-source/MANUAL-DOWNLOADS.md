## 2. Adobe Mixamo (needs a free Adobe login — not scriptable)

https://www.mixamo.com/

The Quaternius Universal rig (UAL1/UAL2, already downloaded) covers idle / walk / jog / sprint / jump start-loop-land /
roll / slide / climb-up / knockback / dance. Mixamo only has to fill the **movement gaps** below.

### Why `Superhero_Male_FullBody.fbx` fails with "unable to map your existing skeleton"

That FBX already contains the Quaternius/UE-mannequin skeleton (`pelvis`, `spine_01`, `clavicle_l`, …). Mixamo only accepts
two kinds of upload: (a) a mesh with **no** skeleton, which it auto-rigs, or (b) a mesh already on a **Mixamo** skeleton.
Ours is neither, so it refuses. Fix: upload the mesh without the skeleton.

### Option A (recommended) — upload the pre-stripped mesh

Already generated by `tools/export-mixamo-mesh.py` (bind pose = T-pose, 1.82 m, textures included):

- `assets-source/mixamo/upload/Superhero_Male_mesh.zip`
- `assets-source/mixamo/upload/Superhero_Female_mesh.zip`

1. Mixamo → **Upload Character** → drop the **.zip** (OBJ + MTL + PNGs inside).
2. Auto-rigger opens → place the 5 markers: chin, wrists, elbows, knees, groin. Skeleton LOD: **Standard (65)** or **No Fingers (25)** (fingers aren't needed for parkour at this camera distance; 25 is lighter).
3. Wait for rigging, click **Next** → character is now on a Mixamo skeleton with our proportions.
4. For each clip in the table: tick **In Place**, then Download → Format **FBX Binary**, Skin **Without Skin** (download the *first* clip **With Skin** once so you also have the rigged mesh), 30 fps, Keyframe Reduction **none**.
5. Save to `assets-source/mixamo/<clip-name>.fbx`.

### Option B (zero friction) — skip the upload entirely

Pick the default **Y Bot** character in Mixamo and download the same clips **Without Skin**. Because we have to retarget
Mixamo → Quaternius rig in Blender anyway, the only thing uploading our own mesh buys is a slightly better preview. If
Option A gives any trouble, do this instead.

### Retarget step (later, Phase 3/5)

In Blender: import `UAL1_Standard.glb` (target rig) + a Mixamo FBX (source rig) → **Rokoko Studio Live** add-on
(free) → Retargeting → auto-map `mixamorig:Hips→pelvis`, `Spine→spine_01`, `LeftArm→upperarm_l`, … → bake → export
all retargeted actions in one `player_anims_extra.glb`.
